# 이미지 파일명 규칙

아래 파일명을 그대로 사용하면 사이트에 자동 반영됩니다.

## 캐릭터 카드

- `lucia.png`
- `rena.png`
- `ria.png`
- `ciel.png`
- `serena.png`
- `isera.png`

## 아바돈

- `abaddon-dragon.png` — 마룡 본체
- `abaddon-polymorph.png` — 여성 폴리모프

권장: 세로형 원본 이미지를 사용하되 중요한 얼굴과 상반신이 중앙에 오도록 구성합니다.
`{{user}}` 장악 이미지는 사용하지 않으며, 리아 몸 장악 이미지는 웹사이트 공개 자산 목록에 포함하지 않습니다.
